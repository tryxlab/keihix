## 2. ストア「詳しい説明」（冒頭に購入前注意喚起を配置）

Google Play ストアでは「続きを読む」をタップする前の冒頭数行が最も読まれるため、**必須条件を最上部に配置** します。

```text
【ご購入前に必ずご確認ください】
本アプリは「開発者サーバー代 0 円・個人情報保持ゼロ」を実現するため、以下の 2 つをご自身でご用意いただく設計になっています。

1. Google アカウント（必須）
   ・撮影したレシートや明細 CSV は、開発者サーバーではなく「あなた自身の Google Drive」に直接保存されます。
2. Gemini API キー（AI 自動読み取り・AI 質問機能に必要）
   ・レシートの自動解析には、Google AI Studio で発行できるご自身の API キー（無料枠あり）の登録が必要です。
   ・※ もし API キーの設定が難しい場合でも、Google Drive 連携が完了していれば「手入力での証憑保存・電帳法ファイル命名・収支集計・CSV 出力」は利用可能です。

■ オープンソースと Play ストア版の位置づけ
KeihiX のソースコードは GitHub で公開しています。技術をお持ちの方はご自身でビルド・OAuth 設定を行って無料で利用できます。
Play ストア版は「Android ビルドや Google Cloud OAuth 設定の手間を省き、すぐ使いたい方・開発者を応援したい方向け」のビルド済みパッケージです。

---

【KeihiX の主な特徴】
■ サーバー代 0 円・ロックインなし
データはすべてあなたの Google Drive 内「確定申告_{年}/」フォルダに保存されます。開発者がサービスを終了しても、手元の画像・PDF・CSV はすべてそのまま残ります。

■ 共有メニュー（Share Target）で 1 タップ取り込み
ブラウザやメールアプリで PDF 領収書や請求書を開いた状態から「共有 → KeihiX」を選ぶだけで、AI が日付・金額・取引先・勘定科目・インボイス番号（T+13桁）を自動抽出します。

■ 電帳法（電子帳簿保存法）の検索要件に対応
・証憑ファイルは「YYYYMMDD_金額_取引先.拡張子」で自動命名
・取引履歴は UTF-8 BOM 付き「transaction_log.csv」に自動追記
・国税庁ひな形に準拠した「事務処理規程」テキストをアプリ内に収録

■ 圏外・API 混雑時も作業が止まらない設計
・圏外時はアプリ内に自動退避し、オンライン復帰後に Drive の pending/ フォルダへ自動バックアップ
・AI 混雑時（503）も「再解析」「手入力（画像付き保存）」「Drive へ一時退避（あとで解析）」の 3 つの逃げ道を用意

■ 収支サマリ・CSV エクスポート・AI 質問
・年別の収入合計／経費合計／差引収支、科目別・月別グラフをスマホ縦画面で見やすく表示
・自分の取引データについて Gemini に自然言語で質問・重複チェック・削除提案の確認が可能
```

## 3. 購入後に「どうしても API キーを入れられない」方への案内

ストアのサポート窓口・note 記事・アプリ内ヘルプ（設定画面「キーを入れられない・お困りの方はこちら」）で、以下を案内します。

1. **Google Workspace（会社・学校アカウント）制限の回避**:
   * 法人・教育機関アカウントでは管理者が Google AI Studio を無効化していることがあります。個人の `@gmail.com` アカウントで [Google AI Studio](https://aistudio.google.com/apikey) を開くと発行できるケースが大半です。
2. **キーなしでのフォールバック運用**:
   * API キーが未登録でも、レシート撮影・PDF 共有後に「手入力で進む」を選べば、証憑ファイルの電帳法準拠リネーム＋Google Drive 保存＋`transaction_log.csv` 記録＋収支集計はすべて動作します。
3. **返金案内**:
   * どうしても意図した利用ができない場合は、Google Play の標準返金フロー（購入直後の返金ボタンまたは Google Play 注文履歴）を利用できる旨を誠実に案内します。
