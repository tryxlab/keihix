# KeihiX 利用ガイド (ユーザーマニュアル)

本書は、確定申告・電帳法対応レシート＆収入管理アプリ **KeihiX（ケイヒエックス）** を利用するための初期設定および日常の操作手順をまとめたガイドです。

---

## 全体の流れ（3ステップで完了）

* **【初期設定】（初回のみ・約3分）:** Googleアカウント連携 ＋ Gemini APIキー（無料）の入力
* **【日常の運用】（1回あたり数秒）:** レシート撮影、またはPDFを「共有」から取り込み
* **【月1回 / 年末】（数分）:** 銀行明細（CSV/PDF）の取り込み ＆ 確定申告コーナーへの転記

---

## 1. 初期設定（初回起動時）

### 1.1 免責事項への同意
アプリ初回起動時に、免責事項のダイアログが表示されます。
本アプリは税理士法に定める税務相談・申告代行を行うものではありません。内容をご確認のうえ、同意チェックを入れて開始してください。

### 1.2 Google アカウント連携（Google Drive）
* **「Google アカウントと連携」** ボタンをタップします。
* 確定申告データを保存したいご自身の Google アカウントを選択します。
* ※本アプリがアクセスするのは、アプリ自身が作成した専用フォルダ（ `確定申告_{年}` ）のみです。ユーザーの Drive 全体の閲覧権限は要求しません。

### 1.3 Gemini APIキー（無料）の取得と登録
AIによる自動文字起こし・データ抽出を行うため、Google AI Studio で無料発行できる API キーを登録します。

* **APIキーの無料取得手順:**
  1. ブラウザで [Google AI Studio](https://aistudio.google.com/) にアクセスし、Google アカウントでログインします。
  2. 左上メニューの **「Get API key」** をクリックします。
  3. **「Create API key」** ボタンを押し、表示されたキー文字列（ `AIzaSy...` ）をコピーします。
  4. KeihiX アプリの設定画面を開き、APIキー入力欄に貼り付けて **「保存」** をタップします。

※APIキーはスマートフォンの安全な暗号化領域（ `EncryptedSharedPreferences` ）にのみ保管され、外部の開発者サーバー等に送信されることは一切ありません。

## 2. 電帳法「事務処理規程」の備え付け（約1分）

電子帳簿保存法（電帳法）では、メールやWebで受領したPDF領収書の保存において「改ざん防止措置」が求められます。

高価なタイムスタンプサービスを契約する代わりに、**国税庁が公式に認めている「事務処理規程」を作成・保管** します。

1. アプリの設定画面から **「電帳法 事務処理規程テンプレート」** を開きます（またはリポジトリ同梱の規程ファイルを利用）。
2. 文中の **「事業主氏名 / 屋号」** をご自身のものに書き換えます。
3. 作成したファイルを PC や Google Drive の任意の場所に保管しておきます（印刷して手元に置いておくだけでも適法です）。

## 3. 日常の使い方（レシート・領収書の保存）

領収書や請求書が発生したその場で、以下のいずれかの方法でアプリへ渡します。

### パターンA：紙のレシート・領収書
1. KeihiX アプリを開き、**「カメラ撮影」** をタップします。
2. レシート全体が写るように撮影します。
3. 1〜2秒で Gemini が **「日付」「金額」「取引先名」「勘定科目」** を自動解析し、入力フォームに初期セットされます。
4. 内容を確認し、必要に応じて手修正して **「保存」** を押します。

### パターンB：Web領収書・PDF明細（★一番おすすめ）
Amazon、メーラー、各種Webサービスで領収書PDFやスクショを開いた状態から直接登録できます。

1. PDFビューアやブラウザの **「共有」ボタン（アイコン）** をタップします。
2. アプリ一覧から **「KeihiX」** を選択します。
3. 自動的にアプリが起動し、PDFの解析結果が表示されます。
4. 内容を確認して **「保存」** を押せば完了です（端末のダウンロードフォルダを探す手間が不要です）。

### パターンC：売上明細・請求書控え（収入）
クラウドソーシングやプラットフォーム（noteやStripe等）からの支払通知書も同様に登録できます。
AIが自動的に **「収入（売上）」** と判定し、差し引かれた **「手数料」** や **「源泉徴収税」** も自動抽出します。

## 4. 銀行口座の明細取り込み（AI対応・どの銀行でもOK）

月に1回、または確定申告直前の年末に、事業用口座の入出金明細を取り込みます。

### どんな銀行の明細でも柔軟に対応
従来の会計ソフトと異なり、**Gemini AIがフォーマットの差異を自動で吸収する** ため、特定の銀行に縛られません。

* 対応例: GMOあおぞらネット銀行、住信SBIネット銀行、楽天銀行、メガバンク、ゆうちょ銀行、地方銀行など

### 取り込み手順
1. ご利用の銀行のインターネットバンキングにログインし、**「入出金明細（CSVまたはPDF）」** をダウンロードします。
2. KeihiX アプリの **「口座明細の取り込み」** から該当ファイルを選択します。
3. AIが明細を自動解析し、以下の処理を行います。
   * **売上（入金）の一括記帳:** 振込元や金額から売上データを生成。
   * **領収書の自動突合（マッチング）:** 口座から出金された金額と、すでに登録済みの領収書データを照合。
   * **未処理アラート:** 「口座から引き落としがあるのに、領収書が保存されていない出金」をリストアップして通知。

## 5. 年末の確定申告（CSVエクスポートと転記）

1年分のデータが蓄積されたら、確定申告書を作成します。

1. KeihiX アプリのメニューから **「当年分のCSVを出力」** をタップします。
2. ご自身の Google Drive に保存されている `確定申告_{年}/transaction_log.csv` が共有・出力されます。
3. CSVファイルを開くと、勘定科目ごとに合計金額が集計されています。
4. 国税庁の **「確定申告書等作成コーナー」** をブラウザで開き、収支内訳書（白色申告）または青色申告決算書の各科目欄に数値をそのまま転記します。

## よくある質問 (FAQ)

### Q. 開発者側に領収書や個人情報が見られることはありますか？
**A. 一切ありません。**
KeihiX には開発者が管理するサーバーやデータベースが存在しません。すべての画像・PDFファイルおよびCSV台帳は、ユーザーご自身の Google Drive 内にのみ保存されます。

### Q. Gemini APIの利用料金はかかりますか？
**A. 個人開発・副業の規模であれば完全無料です。**
Google AI Studio の個人向け無料枠（1分間に15リクエスト、1日1,500リクエストまで）の範囲内で動作します。日々のレシート登録や月数回の明細取り込み程度であれば、無料枠の上限を超えることはまずありません。

### Q. オフライン（電波が届かない場所）でも使えますか？
**A. 一時保存が可能です。**
電波がない場所で撮影した場合、端末内に一時保存（キューイング）され、オンラインに復帰したタイミングで自動的に Gemini 解析と Google Drive へのアップロードが実行されます。
