## 第6回から退避したメモ：Play ストア配布を見据えた「購入前注意喚起」と「キー設定ヘルプ」

ここまで動くようになり、「GitHub でソースコードを公開しつつ、自分でビルドや Google Cloud の OAuth 設定をするのが面倒な方向けに、Google Play ストアで買い切り版として公開するのもありなのでは？」という構想も見えてきました。

ただ、もしストアで有償配布する場合に一番怖いのが、 **「買ったはいいけれど、Google アカウント連携や Gemini API キーが必要だと知らなかった」「どうしても API キーが入れられずに詰まった」** というミスマッチです。

そこで、購入前と購入後（インストール後）のそれぞれで迷わないよう、以下の 3 段階に分けて注意喚起とフォールバック導線を組み込みました（実装済み・実運用検証はこれから）。

* **【購入前】ストア掲載文＆利用ガイドの整備（ `Docs/store_listing_and_setup_guide.md` / `Docs/user_guide.md` ）:**
  Play ストアの説明欄冒頭（折りたたまれる前に必ず目に入る位置）に、Google アカウント必須・Gemini API キー必要・OSS 自前ビルドとの違いを明記するテンプレートを用意しました。
* **【購入・インストール後】初回起動画面（ `DisclaimerScreen.kt` ）:**
  決済・インストール後に最初に開く免責画面の先頭にも **「ご利用に必要なもの（事前確認）」** カードを置き、セットアップに入る前に改めて前提条件を確認できるようにしました（万一「想定と違った」という場合でも、購入直後であれば Google Play の標準返金手続きを取りやすいタイミングになります）。
* **【設定時】設定画面（ `SettingsScreen.kt` ）:**
  **「Google AI Studio でキーを取得（無料）」** ボタンから直接発行ページを開けるようにし、その下に **「キーを入れられない・お困りの方はこちら」** ダイアログを追加しました。会社・学校の Google Workspace アカウント制限時は個人の `@gmail.com` を使う対処法や、 **API キーがなくても「手入力で進む」から電帳法リネーム保存・CSV 記録・収支集計はすべて使えること** を案内しています。
